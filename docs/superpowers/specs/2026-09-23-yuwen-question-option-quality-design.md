# 语文实虚词题目选项质量修订设计

## 目标

修订统一高中、初中实虚词题目的选项生产逻辑，保证每条例句的两道题都将第一个选项设为正确答案，并提高混淆项与辨析例句的内容质量。

本次只调整题目生成和预览展示，不改变三张正式数据表的字段结构。

## 数据范围与来源

- 当前统一词义数据：`sql/edu_chn_word_sense.sql`。
- 当前统一教材关系：`sql/edu_chn_word_catalog.sql`。
- 当前统一题目数据：`sql/edu_chn_word_question.sql`。
- 课内例句优先使用现有词义数据中的可靠原文和译文。
- 课外例句允许参考用户提供的华夏文库文言文词典页面：
  `https://wyw.hwxnet.com/view/hwxE4hwxBAhwxBA.html`
- 外部参考内容在生成前人工整理并固化到本地资源文件，生成 SQL 和预览页时不实时联网。
- 无法确认原文、译文或词义的内容不自行编造，使用“暂无例句”占位并保留后续人工补充空间。

## 题型一：词义选择

每个有可靠原文例句的词义生成 1 道题，固定生成 4 个选项：

```json
[
  {"content": "当前词义", "correct": true},
  {"content": "混淆释义 1", "correct": false},
  {"content": "混淆释义 2", "correct": false},
  {"content": "混淆释义 3", "correct": false}
]
```

混淆项按以下优先级补齐：

1. 同一原词在统一数据中的其他词义，去重后按教材版本、分册和词义顺序优先。
2. 外部参考词典中该词的其他常考义项。
3. 项目维护的常考义项/反义词/字面义候选配置。

候选不足时不重复当前正确释义，不使用没有语义依据的随机词。所有候选释义沿用词性前缀格式，例如 `<名>农历每月十五日`。

## 题型二：辨析选择

每个有可靠原文例句的词义生成 1 道题，固定生成 2 个选项：

```json
[
  {"content": "同义例句", "correct": true},
  {"content": "异义例句", "correct": false}
]
```

选项 A（正确项）检索优先级：

1. 统一词义数据中同一原词、同一词义的其他课内例句，排除当前例句。
2. 外部参考资源中同一词义的课外例句。
3. 找不到可靠例句时写入 `暂无例句`，仍保持 `correct=true`，由预览页标红提示人工补充。

选项 B（错误项）检索优先级：

1. 统一词义数据中同一原词、其他词义的例句。
2. 外部参考资源中同一原词、其他词义的例句。
3. 找不到可靠例句时写入 `暂无例句`，保持 `correct=false`，由预览页标红提示人工补充。

题型二不再自动编写“该词表示某某”的伪例句。

## 外部例句本地化结构

新增本地资源文件保存人工确认后的外部参考内容，建议结构如下：

```js
{
  word: '望',
  meaning: '<名>农历每月十五日',
  example: '壬戌之秋，七月既望，苏子与客泛舟游于赤壁之下。',
  exampleTrans: '壬戌年秋天，七月十六日，苏轼和客人乘船游览赤壁之下。',
  source: '《赤壁赋》｜外部词典参考'
}
```

资源只作为生成输入；正式入库仍遵循现有 `edu_chn_word_question.options_json` 结构，不新增字段。

## 预览页展示

- 题型一继续展示 4 个选项，A 固定正确。
- 题型二继续展示 2 个选项，A 固定正确。
- `content === '暂无例句'` 的选项增加不可用标识和红色样式。
- 预览页不直接展示答案状态，红色只表示“该内容待人工补充”，避免与正确/错误颜色混淆。
- 复制按钮继续复制当前 `sense_id`、两个 `question_id`、词义、篇目、原文和译文等定位信息。

## 校验标准

生成后必须自动校验：

- 有可靠例句的词义均有题型一、题型二各 1 道。
- 题型一恰好 4 个选项，首项 `correct=true`，其余为 `false`。
- 题型二恰好 2 个选项，首项 `correct=true`，第二项为 `false`。
- 题型一混淆释义不重复当前正确释义。
- 题型二选项只使用当前数据或本地外部参考资源中的例句；缺失时只能是 `暂无例句`。
- 所有 `暂无例句` 在预览页标红。
- SQL 中 `sense_id`、题目 ID、教材关系无孤儿或重复关系。
- `git diff --check` 和预览页脚本语法检查通过。
