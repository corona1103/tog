# 语文自学“积累本”交互 Demo 设计说明

- 日期：2026-09-08
- 范围：学生平板横屏交互 Demo
- 依据：yuwen/【66】学生平板增加语文自学”默写本“.md
- 状态：待实现

## 1. 目标

制作一个可点击、可输入、可提交并能看到结果反馈的学生平板 Demo，用于呈现语文自学“积累本”的核心功能效果。

Demo 需要覆盖两类入口：

1. 古诗文背默；
2. 文言文实词/虚词。

重点展示用户从首页进入模块、选择内容、完成学习或练习、提交答案、查看结果的连续体验。

## 2. 约束

- 固定平板横屏布局，按 16:10 画布设计。
- 不提供竖屏切换。
- 窄视口不重排为竖屏，提示用户使用横屏查看。
- 使用本地模拟数据，不连接后端。
- 不制作老师小屏、管理后台和教室大屏的详细页面。
- 不实现真实 OCR、AI 判题、账号、联网和数据持久化。
- 视觉重点放在信息层级、学习路径和核心交互，不追求最终 UI 规范交付。

## 3. 页面与状态结构

采用单 HTML 页面内的状态流转方式，保留统一的学生平板外壳和返回路径。

### 3.1 首页：积累本

入口板块：

- 古诗文背默；
- 文言文实虚词；
- 我的学习（轻量展示入口，可用于呈现学习进度和成就）。

首页展示：

- 本周学习概览；
- 最近学习内容；
- 两个主要模块入口；
- 推荐或继续学习入口。

### 3.2 古诗文模块

流程：

积累本首页 → 古诗文背默 → 教材/册次/章节 → 诗文卡片 → 诗文详情。

诗文卡片展示：

- 标题、作者、朝代；
- 内容所属章节；
- 理解与背诵、直接默写、理解性默写三类完成状态；
- 待开始、部分正确、全对三种状态。

诗文详情固定提供三个 Tab：

1. 理解与背诵；
2. 直接默写；
3. 理解性默写。

#### 理解与背诵

- 展示原文；
- 支持显示/隐藏译文；
- 支持开始背诵；
- 古文按段隐藏原文，只展示首字提示；
- 支持“提示看看”“继续背”“我背完了”；
- 完成一段后进入下一段；
- 全文完成后允许进入直接默写。

#### 直接默写

提供三种模式：

- 上下句默写，默认模式；
- 全篇默写；
- 抽查默写。

交互要求：

- 上下句模式逐题作答，提交后即时显示对错；
- 全篇模式使用多行输入，支持换行和中文标点，提交后进入逐字比对结果；
- 抽查模式随机呈现篇目中的指定内容；
- 支持查看原文、清空重填、重新默写；
- 结果展示正确率、用时和错误位置。

#### 理解性默写

- 支持全部、情境提示、主题归类、手法识别筛选；
- 展示题号、题干摘要、题型标签、难度和作答状态；
- 进入答题后展示题干、输入框、提示、跳过；
- 提交后展示正确/错误、学生答案、标准答案和解析；
- 支持下一题、收藏本题；
- 完成后展示总分、耗时、正确题/错误题列表和错题重练入口。

### 3.3 文言文实虚词模块

流程：

积累本首页 → 文言文实虚词 → 实词/虚词 → 词卡学习或词汇练习。

词卡学习：

- 支持正面/背面切换；
- 正面展示目标词、拼音、课文例句和当前释义；
- 背面展示词义、词性/用法、例句出处、原文和翻译；
- 支持左右切换词卡；
- 支持标记“学会”。

词汇练习：

- 选择实词或虚词；
- 选择内容范围和练习数量；
- 支持词义选择和辨析选择；
- 正确后进入下一题；
- 错误后进入详细词卡，定位当前释义和例句，再允许继续；
- 练习结束展示正确数、错误数和巩固入口。

## 4. 交互状态与数据

仅在页面内维护临时状态：

- 当前模块；
- 当前教材、章节、篇目；
- 当前详情 Tab；
- 背诵段落和完成进度；
- 当前默写模式、输入内容、题目进度；
- 当前词卡索引、正反面和是否学会；
- 当前练习题、答题结果和汇总结果。

刷新页面后状态可以重置，不做本地存储。

## 5. 横屏实现

- 主容器保持横向平板比例；
- 页面最小宽度按横屏交互设计；
- 视口高度不足时允许页面内部滚动，但不改变横向布局；
- 检测到窄视口时显示横屏提示层；
- 不提供 portrait CSS、竖屏导航或竖屏替代布局。

## 6. 错误和边界状态

- 未输入答案时，提交按钮不可用或提示先完成作答；
- 提前提交时，空答案按未作答展示；
- 切换模块前保留返回首页入口；
- 退出未提交的练习时提示当前内容不会计入本次结果；
- 长文本结果页支持滚动查看；
- 题目完成后避免继续点击下一题造成越界；
- 在不支持的后续能力处使用明确的“后续开放”状态，不伪装成已实现能力。

## 7. 验收标准

- 用户可以从积累本首页分别进入古诗文和文言文实虚词两个模块；
- 古诗文三类 Tab 均可进入并完成至少一条核心交互；
- 直接默写支持输入、提交和结果展示；
- 理解性默写支持题目切换、作答、判定和总结；
- 文言文模块支持词卡翻面、标记学会、选择题作答和错误巩固；
- 所有交互均在固定横屏布局中完成；
- 窄视口不出现竖屏重排；
- 页面无后端依赖，可直接在现有 Demo 目录打开。

## 8. 明确不纳入本次 Demo

- 教师小屏和管理后台的完整交互；
- 教室大屏实时互动；
- 手写输入；
- 真实机器批改；
- 后端接口、数据同步和埋点；
- 完整三期产品能力，只呈现未来模块的规划性入口或必要占位。
