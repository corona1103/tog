# 学习记录按模块展示设计

## 目标

将“我的学习记录”改为按学习模块查看，不提供“全部”汇总；古诗文记录按日期分组，并将同一篇目的同一学习类型聚合展示，同时保留原始行为用于详情回看。

## 交互结构

- 页面顶部只保留两个模块页签：`古诗文`、`实虚词`。
- 默认进入`古诗文`页签。
- 删除`全部`筛选项，两个模块之间切换时只切换展示范围，不改变原始记录。
- 日期作为分组标题展示；单条记录不显示具体时分。
- 日期标题可显示“今天”“昨天”或日期，但不在记录行重复显示日期。

## 古诗文记录模型

展示层基于已有原始学习记录计算聚合结果，不改写原始记录。

### 背诵

- 聚合键：日期 + 篇目 + `recite` 类型。
- 同一日期、同一篇目的多次背诵合并为一条。
- 标题格式：`《篇目》 背诵n次`。
- 主按钮：`查看原文`，进入对应篇目的古诗文详情页。
- 排序时间：该篇目最后一次背诵完成时间。

### 默写

- 聚合键：日期 + 篇目 + `direct` 或 `comprehension` 类型。
- 同一日期、同一篇目、同一默写类型合并为一条；不同默写类型不合并。
- 标题格式：`篇目 直接默写n次`或`篇目 理解性默写n次`。
- 主按钮：`查看详情`。
- 详情按默写轮次展示每次提交结果；每轮保留题目、用户作答、正误、正确答案。
- 排序时间：该聚合记录最后一次默写提交时间。

### 练习

- 聚合键：日期 + 篇目 + `practice` 类型。
- 同一日期、同一篇目的练习合并为一条。
- 标题格式：`篇目 练习x题`。
- 主按钮：`查看详情`。
- 详情展示该聚合内所有做过的题目和作答结果，题目允许重复；每道题包含题干、正误和正确答案。
- 排序时间：该篇目最后一次练习提交时间。

### 随机抽查

- 每一轮随机抽查单独生成一条记录，不与篇目练习合并。
- 标题格式：`随机抽查n题`。
- 主按钮：`查看详情`。
- 详情展示该轮实际抽取的全部题目、用户作答、正误和正确答案。
- 排序时间：该轮发起时间。

## 排序规则

- 先按日期倒序分组。
- 日期组内，篇目聚合记录按聚合项最后更新时间倒序；随机抽查按发起时间倒序。
- 页面不显示具体时间，但排序必须使用原始记录中的时间字段。
- 聚合只影响展示，不删除、不覆盖原始记录。

## 记录行展示

每条记录主体只保留：图例、标题、日期分组下的记录内容和一个动作按钮；不展示具体时分、正确率、题目数之外的附加统计。

## 边界规则

- 同一天同篇目同类型的多次行为合并；跨日期不合并。
- 默写的多次提交结果全部保留，不能只显示最后一次。
- 练习的重复题目全部保留，不能去重。
- 没有可回看的原始详情时，仍显示聚合记录，并在详情区域展示空状态。
- 记录缺少篇目时，不参与篇目聚合，按原始类型保留为独立记录，避免错误合并。

## 验收标准

给定行为序列：观沧海背1次、观沧海直接默1次、次北固背1次、次北固练3题、观沧海再背1次、随机抽查1轮，页面应按日期显示：

1. 随机抽查1次
2. 观沧海背2次
3. 次北固背1次
4. 次北固练3题
5. 观沧海直接默1次

其中每条记录不显示具体时分；点击背诵记录进入篇目原文，点击默写、练习和随机抽查记录均可回看完整历史详情。
