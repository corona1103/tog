# 语文积累本实虚词学习与复习答题流程设计

## 1. 背景

当前实虚词练习页的答题逻辑是：选择错误后锁定选项并进入词卡，选择正确后自动进入下一题。该行为无法支持学生在同一道题内继续尝试，也没有区分学习模式和复习模式。

本次调整仅针对学生端功能 Demo 的交互状态，不修改实虚词内容数据、题目数据、SQL 或审核预览页。

## 2. 目标行为

### 学习流程

- 首次选择正确：进入当前词卡详情。
- 选择错误：保留当前题目并允许继续选择其他选项。
- 选择错误后再次答对：进入当前词卡详情。
- 进入词卡后，用户手动点击“继续下一题”才进入下一题。

### 复习流程

- 首次选择正确：自动进入下一题，不打开词卡。
- 首次选择错误：保留当前题目并允许继续选择其他选项。
- 选择错误后答对：进入当前词卡详情。
- 进入词卡后，用户手动点击“继续下一题”才进入下一题。

### 共同规则

- 答错提示为“回答错误，再选一次”。
- 答题错误后不禁用选项；用户可以继续尝试。
- 当前题只在第一次答错时加入当前练习轮的错题队列，避免重复加入。
- 保留现有“错题重做”机制：当前轮完成后，错题仍可进入对应的错题重做阶段。
- 答题状态、词卡状态和题目索引切换时，不改变现有教材范围、词卡内容和题目顺序。
- 最后一题进入词卡后，点击“继续下一题”仍按现有流程进入下一阶段或完成结果页，不产生越界索引。

## 3. 状态设计

在现有 `wordPractice` 状态基础上增加一个当前题级别的标记：

- `wordPracticeHadWrong`：当前题是否已经发生过错误选择。

状态转换如下：

```text
题目待作答
  ├─ 学习 + 答对 → 词卡
  ├─ 复习 + 首次答对 → 下一题
  └─ 答错 → 当前题继续作答，并标记 hadWrong=true
                         └─ 再答对 → 词卡

词卡
  └─ 点击“继续下一题” → 清理当前题状态并进入下一题/下一阶段
```

进入新题、进入新的题型阶段、开始新一轮练习和完成练习时，都要清理 `wordPracticeHadWrong`。

## 4. 实现边界

修改范围限定为：

- `/Users/tal/Desktop/tog/demo/yuwen/accumulation/index.html`

主要调整：

1. 答题函数区分学习/复习模式和当前题是否曾答错。
2. 错误选择不再触发词卡定时跳转，选项保持可操作。
3. 正确选择根据状态决定自动下一题或打开词卡。
4. 词卡“继续下一题”统一清理当前题状态后推进。
5. 题目入错题队列时去重。
6. 调整反馈文案和必要的按钮禁用状态。

不调整：

- 题目内容、选项内容、词卡内容和学习记录数据结构。
- SQL 文件和内容生产脚本。
- 古诗文流程。
- 实虚词审核预览页的“查看题目”交互。

## 5. 验证标准

至少验证以下路径：

1. 学习模式首答正确：进入词卡；点击“继续下一题”进入下一题。
2. 学习模式首答错误：仍停留在当前题；可点击其他选项；答对后进入词卡。
3. 复习模式首答正确：不进入词卡，自动切换下一题。
4. 复习模式首答错误：仍停留在当前题；答对后进入词卡；点击“继续下一题”才切换下一题。
5. 同一题连续答错：选项始终可继续操作，错题队列不重复增加。
6. 最后一题在学习和复习两种模式下均能正常进入结果或下一阶段，不越界。
7. 现有词卡翻面、标记重点、继续下一题和练习结果弹窗不受影响。
