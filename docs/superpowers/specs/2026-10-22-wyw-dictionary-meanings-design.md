# 文言文字典释义汇总设计

## 目标

根据用户提供的汉字清单，从指定文言文字典页面整理拼音、词性、释义、例句和出处，并生成可持续追加和检索的 Markdown 文档。

## 输出结构

- 输出文件：`outputs/文言文字典释义汇总.md`
- 每个汉字使用独立小节。
- 每条记录使用五元组：字、拼音、词性与释义、例句、出处。
- 多音字按读音分组；同一释义对应多个例句时拆分为多条记录。
- 不收录音频码、部首、笔画、笔顺及相关词语。

## 数据处理规则

- 以字典页面“详细释义”区域为主要来源。
- 保留页面提供的所有编号义项和对应例句；没有例句的义项保留空出处字段。
- 对明显的 HTML 标记缺损或通行文本错字做最小必要修正，并在文档末尾说明。
- 生成后检查汉字覆盖、记录格式和重复/空记录情况。
