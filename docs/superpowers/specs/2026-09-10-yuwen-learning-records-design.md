# 语文积累本“我的学习记录”设计

## 目标

在现有语文积累本静态 Demo 中增加“我的学习记录”二级页面，按时间和类别回看学生的古诗文背诵、默写/练习、随机抽查和实虚词学习过程，并提供回到原内容的入口。

## 页面结构

### 1. 学习记录首页

- 顶部展示页面标题“我的学习记录”、说明文案和“返回积累本”。
- 类别筛选：全部、古诗文、实虚词。
- 时间线按日期倒序分组，日期组内按学习时间倒序排列。
- 单行记录主体只展示：类别图例、记录标题、学习时间和操作入口。
- 预置示例数据，首次打开页面也能看到完整时间线。

### 2. 记录类型与入口

| 类型 | 标题示例 | 操作 | 操作结果 |
| --- | --- | --- | --- |
| 背诵 | 《观沧海》 | 查看篇目 | 进入对应篇目详情，并定位到背诵区域 |
| 理解性默写 | 观沧海 理解性默写 5题 | 查看详情 | 展开本次全部题目、作答、正确答案和对错 |
| 直接默写 | 观沧海 直接默写 5题 | 查看详情 | 展开本次全部题目、作答、正确答案和对错 |
| 随机抽查 | 随机抽查 5题 | 查看详情 | 展开实际抽查题目、所属篇目、作答、正确答案和对错 |
| 实虚词 | “负” | 查看词卡 | 进入对应词卡详情 |

同一次默写或随机抽查中的多道题合并为一条记录，题目明细只在“查看详情”中展开，不按题目拆成多条时间线记录。

实虚词按学习日期展示。当天学过多个词时，默认每个词保留一条可点击记录；页面通过日期组体现“按天展示”。

## 数据模型与数据流

统一使用 `learningRecords` 活动日志。每条日志至少包含：

```js
{
  id, date, time,
  category: 'poem' | 'word',
  type: 'recite' | 'direct' | 'comprehension' | 'random' | 'wordCard',
  title, poemId, wordKey,
  questions: [{ question, userAnswer, correctAnswer, correct }],
  status, rate
}
```

- `recite`：记录篇目、学习时间、已背句数和背完次数；点击后复用现有篇目详情路由。
- `direct`、`comprehension`、`random`：一次提交生成一条日志，`questions` 保存该批次全部题目；正确率按空数统计，详情展示每题作答与正确答案。
- `wordCard`：记录词语和学习时间；点击后复用现有词卡路由。
- 预置日志与用户操作日志合并展示，统一经过日期分组和类别筛选。

## 交互规则

- 首页“我的学习记录”打开 `learningRecords` 路由。
- 返回积累本回到 `home`，不清空日志。
- 类别筛选只改变当前时间线，不改变日志数据。
- “查看详情”在当前页面展开或收起题目明细；同一时间只展开一条记录，避免长页面过度膨胀。
- 做题详情展示：题干、学生答案、正确答案、对错标识；不展示“需要订正”和解析文案。
- “查看篇目”进入对应篇目详情，定位背诵区域；“查看词卡”进入对应词卡。
- 不保留未完成过程：退出背诵、未提交默写、未提交练习不生成完成日志。
- 同一批次题目只写入一次日志，避免重复提交造成重复记录。

## 背诵完成规则同步

- 最后一句点击“背完了”后不跳转新页面，当前背诵区域按钮替换为“重新背”和“去默写 3s”。
- “去默写 3s”显示 3 秒倒计时，倒计时结束自动进入直接默写。
- “重新背”从头开始本次背诵。
- 完成全文后才更新背完次数并写入背诵日志；中途退出再次进入从头开始。

## 异常与边界

- 没有记录时展示空状态，并保留类别筛选和返回入口。
- 记录引用的篇目或词卡不存在时，仍展示原记录，并在进入时提示“内容暂不可用”。
- 题目答案为空时按未作答处理，不影响查看详情。
- 多次完成同一篇目按实际完成次数写入多条背诵活动记录；背诵统计仍沿用现有累计规则。

## 验证范围

- 首页入口能打开并返回学习记录页。
- 示例数据能按日期、类别正确筛选。
- 三类做题记录均能合并展示，并能查看完整题目和作答结果。
- 背诵记录能回到篇目详情，词语记录能回到词卡。
- 实际完成一次背诵、默写、理解练习、随机抽查和词卡学习后，日志能追加且不重复。
- 既有首页、篇目列表、篇目详情、默写和词卡流程不受影响。
